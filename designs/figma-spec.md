# PixelCut AI

A premium AI background remover web app concept built with React + Vite. This project includes a polished UI, upload workflow, background-removal simulation, and Figma-ready design specs.

## Features

- Clean landing page and product-style hero
- File upload + preview panel
- Remove background simulation flow
- Smart presets for studio, nature, and product looks
- Responsive layout for desktop and mobile
- Figma-ready design direction and mock screens

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Design direction

The app follows a premium SaaS aesthetic with:

- deep navy background
- electric violet primary accent
- soft cyan secondary accent
- rounded cards and glassy panels
- strong editorial typography

## Figma-ready artifacts

The design specs and mock screens are in the `designs/` folder.

## Project structure

- `src/App.jsx` — main app UI and interactions
- `src/styles.css` — full visual design system
- `designs/figma-spec.md` — Figma planning document
- `designs/*.svg` — mock screens for concept review

## Notes

This is a front-end concept app designed to showcase the user flow and UI. You can connect it to a real AI background-removal backend later using an API such as Remove.bg, Clipdrop, or a custom inference service.
